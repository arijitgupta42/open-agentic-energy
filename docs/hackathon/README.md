The official rules say an entry must conform to the specification as it stood when the
submission period opened (11 November 2026, 8:00 pm Pacific). The copy here is from the
day after. The upstream repository says it changes often, so before submitting, compare
this copy with upstream and read the Devpost rules and updates pages again: the digest
is a summary, and the Devpost pages are the authority.
