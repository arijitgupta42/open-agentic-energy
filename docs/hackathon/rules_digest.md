# Open Agentic Web Challenge: rules digest

A summary in our own words of the [Devpost overview](https://cognizant-agenticweb.devpost.com/)
and the [official rules](https://cognizant-agenticweb.devpost.com/rules), read on
13 November 2026. The Devpost pages are the authority. Read them again before submitting.

## What to build

A working open agentic website, built with standard open web technologies, that conforms
to the MVP specification in the `cognizant-ai-labs/agentic-web` repository. Everything
must be open source.

## What the submitted public URL must hold

1. A publicly accessible, conforming `.json` file that describes an agent network and its
   capabilities.
2. A `runtime` file that runs the agent network in the browser.
3. An interface through which users or agents interact with the agent network.
4. Optional: an interface for configuring the LLMs and keys the agents use.
5. The agent network interacting with the website. Optionally it interacts with other
   agentic websites, or other agentic websites can call it.

## What to submit on Devpost

- The public URL of the open agentic website.
- A text description of its features and functionality.
- A demo video under two minutes (judges need not watch beyond that), which:
  - shows the project running in a web browser;
  - has the entrant explaining the project, not an AI-generated narration;
  - is public on YouTube, with the link on the submission form;
  - has no third-party trademarks or copyrighted music or material without permission.
- One or more screenshots of the website.
- If Mozilla Otari was used: the email on the Otari account, and a sentence or two on a
  problem met and how Otari could improve.
- Optional: links to, and descriptions of, extra tools or services shared with the
  community. These can count under Potential Impact.

## Judging

Stage one is pass or fail: is the project a conforming open agentic website?

Stage two scores passing entries on four equally weighted criteria:

1. **Technological implementation.** How well the project is built, and how effectively
   it uses the open agentic web specification.
2. **Design.** A complete, coherent product experience, not only a technical proof of
   concept.
3. **Potential impact.** A credible case that it solves a real problem for a real
   audience, and whether it shares tools or services with the community.
4. **Quality of the idea.** A creative, non-obvious use of an open agentic website that
   shows real understanding of the problem.

## Other conditions

- The project must be new, or significantly updated during the submission period (then
  explain the updates).
- It must be publicly accessible, run consistently in a current web browser, and work as
  the video and description show.
- It must stay free for the sponsor, the administrator and the judges to test until
  judging ends.
- The work must be the entrant's own and must not infringe anyone's rights. Third-party
  integrations and components must be used under their own terms.
- It must not have been built with financial or preferential support from the sponsor or
  the administrator.
- All materials must be in English, or come with an English translation.
- Several submissions from one entrant must differ substantially from each other.
- Entrants must be of the age of majority where they live. Some countries and regions
  are excluded: see the official rules.
- Employees of the sponsor, its partners and their affiliates may enter, but only for
  the employee prize.
