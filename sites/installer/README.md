# Heatwright Home Energy

The site of a fictional installer of air-source heat pumps and solar panels, with an
assistant. A visitor gets an indicative estimate and requests a survey. Everything on it
is fictional, and nothing leaves the page except what the visitor sends to the LLM
provider they choose.

- **Live:** https://heatwright-installers.open-agentic-energy.workers.dev/
- **Local address:** http://localhost:8081/ (run `npm run serve` from the repository root)
- **Network URL:** `http://localhost:8081/heatwright_installers`
- **Agents:** heatwright_assistant
- **Actions:** get_installer_state (read), set_estimate (write), request_survey (irreversible)
- **Calls:** Fernbrook Retrofit Grants and Emberwick Energy, after the visitor agrees on a consent card
- **MCP tools at `/mcp`:** list_products, estimate

Other agent sites can run this network at its network URL. It then runs in their
visitor's browser, on that visitor's key. It has none of this site's `website_*` tools
there, so it reads this site's public figures from its read-only MCP server at `/mcp`
(`server/`) and points to this page for anything personal or anything that changes state.
A calling site's visitor also gets a card for each partner this network asks.

The assistant sends the visitor's messages, and the page data it reads, to the LLM
provider the visitor picks. State lives in page memory: refreshing the page resets it.

## Files

- `index.html`, `styles.css`, `favicon.svg`: the page, with the assistant section.
- `js/app.js`: the page object, `App.page`: the state reader and one method per operation.
- `js/*-data.js`, `js/*-rules.js`: demo data and business rules.
- `site-actions.js`: registers the operations the assistant can call.
- `site.js`: boots the assistant and shows its confirmation dialog.
- `heatwright_installers.hocon`: the agent network's source.
- `agent-manifest.json`, `links.json`: the public files that describe the network.
- `_headers`: the headers a static host must send.
- `heatwright_installers.network.json`, `agent-mcp.json`, `.well-known/`, `bridge/`: generated by
  `npm run build`. Do not edit them by hand.
- `runtime/`: the browser runtime, copied unchanged from `tools/agentify-website/runtime/`.
- `tests/`: Node tests. Run `npm test` from the repository root.

See the repository's `docs/` for how to develop, test and host it.
