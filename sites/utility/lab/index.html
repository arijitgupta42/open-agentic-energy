These checks run small test networks in this page on the runtime's built-in mock model. They need no API key, send nothing to any AI provider, and change nothing on the account page.

Section 6 of the open agentic web specification asks a runtime to stop an invalid network, a composition cycle, an over-budget request and a denied origin, each with a visible error.
